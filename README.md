## The fortune

> You will spend an hour naming the variable perfectly. Within a week it will be called data2.

One line, 92 characters — inside the 120-character limit.

## Why this wins

This is a real fortune cookie message for an engineer, and it walks past every stock joke in the pile — no Friday deploy, no merge conflict, no "it works on my machine", no lucky 404/500, no 3 a.m. page. Instead it tells the one prophecy every engineer has already lived: you give a variable an hour of loving care, a name so perfect it feels like literature — and a week later the codebase, in its infinite mercy, calls it `data2`. The punchline lands on the first read because the demotion is instant and total: "perfectly" to "data2" in nine words. It is specific, visual, and fresh — naming grief is the oldest engineer pain nobody in this field of hundreds of Friday-deploy fortunes thought to bake into a cookie.

## Run it

```bash
MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes the fortune (one line, 92 characters, no trailing newline) to `out/entry.txt`, verifies it by reading it back, and prints its SHA-256. Output is deterministic and byte-identical on every run.
